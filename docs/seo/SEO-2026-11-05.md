# SEO pass, 2026-11-05 (not deployed yet)

## Done in code
- `/sitemap.xml`: built live by `api/media.ts?sitemap=1`. It lists the static pages, every visible category and every active real product (with image and lastmod). Sample (`demo`) products are left out.
- `robots.txt`: has the Sitemap line, and blocks the admin, account, checkout, search, wishlist and call pages.
- `/catalog/products.json`: now proxied through `api/media.ts?catalog=1`. The old rewrite to r2.dev returned index.html on Vercel, so every visit read Firestore (slower, and it cost reads).
- Sample products: `noindex` and no Product schema, so test listings never reach Google.
- Home: a keyword title, a canonical, and Organization + WebSite JSON-LD. `sameAs` fills in once `BRAND.social` has links.
- `og:site_name` and `og:locale` (en_IN) for link previews.
- Google Search Console: the property `https://www.iconoiq.com/` is added (ICONOIQ Chrome). The verification file is `public/google5781a126ae83ed58.html`.

## After the deploy (team)
1. Search Console > VERIFY (HTML file method) > Sitemaps > submit `sitemap.xml`.
2. Bing Webmaster Tools > import from Search Console.
3. Check that `https://www.iconoiq.com/catalog/products.json` returns JSON and that `/sitemap.xml` lists the categories.

## Only the client or team can do
- Real products: a title with the main keyword, a 150-300 word description and alt text on every photo. Then remove the demo catalogue.
- Social links in `BRAND.social` (Instagram, YouTube, Facebook).
- A Google Business Profile, only if there is a real address or service area.
- Off-page: listings (IndiaMART, JustDial), partner schools, dance academies and temples linking to the site, Instagram/YouTube reels that link to product pages, and guest posts on iconography and Bharatanatyam blogs.
- Later: blog or guide pages for the keyword themes below.
