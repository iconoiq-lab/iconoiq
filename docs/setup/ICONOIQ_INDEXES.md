# ICONOIQ Firestore indexes (one-click links)

The project's admin key can deploy rules but not indexes, and `firebase deploy` here is logged in with another Google account. Open each link while signed in to the Google account that owns `iconoiq-85b53` (the ICONOIQ Chrome) and press **Create index** (or **Save**). They match `firestore.indexes.json`; each takes a few minutes to build. Without the first four the hero, the home banners and the product lists stay empty.
